## 发放与回收建议
1. 上线后第 2 周发放（用户已有真实使用体验）
2. 先发班级/社团群，邀请填写后可参与小抽奖（如奶茶券）提高完成率
3. 回收目标：≥50 份有效答卷
4. 回收后按以下维度分析：
   - NPS（Q9）：≥40 算健康；9-10 分占比高说明有自传播潜力
   - 功能满意度（Q4）：平均分 <3.5 的功能优先优化
   - 「以一换一」规则（Q5-Q8）：若 Q5「完全不知道」比例高 → 加强 UI 引导（如首次进入资料库弹规则）；若 Q7 不愿意分享比例高 → 考虑放宽限制或改为上传审核奖励
   - 新功能呼声（Q10）：前 3 项进入下个迭代 backlog
